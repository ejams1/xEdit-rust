# Phase 6: Scripting


- **Model:** Fable 5.1 for the interpreter, because script compatibility is the most important goal and JvInterpreter semantics are undocumented. Sonnet 5.5 for the host bindings once the binding pattern exists.
- **Port:** A Pascal interpreter compatible with the JvInterpreter dialect, and all host registrations bound to `xedit-session` commands. Scripts that build VCL forms run against a form shim in the GUI and fail with a clear error when headless.
- **CLI:** `xedit script run|list|check`.
- **Skills:** `writing-xedit-scripts` for agents that need custom batch logic.
- **Gate:** All 150 shipped `.pas` scripts parse (`xEditAPI.pas` included). Every script that uses no form produces the same output and the same plugin bytes as the oracle.
