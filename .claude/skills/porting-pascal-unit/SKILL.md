# Porting a Pascal unit

The upstream source is a checkout of https://github.com/TES5Edit/TES5Edit at the commit in `upstream-map.toml`. Read `docs/PLAN.md` for the crate layout and the design rules.

## Procedure

1. Find the unit in `upstream-map.toml`. If its status is `replaced` or `not-ported`, stop and read the note.
2. Read the whole Pascal unit, and the units it uses for anything whose behaviour you depend on. Do not port from memory of how xEdit behaves.
3. Choose the crate from the table in `docs/PLAN.md`. Create the crate when it does not exist yet, with `edition.workspace = true` and `license.workspace = true`.
4. Create one Rust module per unit. Drop the `wb`/`xe` prefix and use snake case: `Core/wbLoadOrder.pas` becomes `crates/xedit-loadorder/src/load_order.rs`.
5. Start the file with the MPL-2.0 notice from `NOTICE`, then `// Ported from xEdit: <unit path>`.
6. Keep upstream names, converted to Rust case and without the `wb`/`xe` prefix: `wbIsPlugin` becomes `is_plugin`. The definition builder API is the exception and keeps the prefix (`wbStruct` becomes `wb_struct`), so that definition files stay line-for-line comparable. Keep the order of declarations the same as upstream so that an upstream diff maps onto the Rust file.
7. Port behaviour exactly, including quirks. When upstream behaviour looks wrong, port it as it is and add a comment that starts with `UPSTREAM-QUIRK:`. Parity comes before correctness.
8. Do not port Delphi plumbing: reference counting, interface GUIDs, memory manager calls, VCL message pumping.
9. When the unit adds an operation a user can run, register a command in `xedit-session` and follow the `adding-a-command` skill. Set the matching entries in `coverage/ledger.toml` to `covered` with the command name.
10. Add tests. Use unit tests for pure logic and a parity test (see the `checking-parity` skill) for anything that reads or writes game files.
11. Set the unit in `upstream-map.toml` to `ported` with its `rust` path. For a partial port keep `pending` and say in `note` what is missing.
12. Run `cargo fmt`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` and `cargo xtask check`.

## Rules

- Never copy code from a GPL project. Dependencies must pass `cargo deny check licenses`.
- No `unsafe` without a `// SAFETY:` comment. SIMD code needs a scalar fallback with identical output.
- Output must not depend on thread count or CPU features.

## Porting a Sniff processor

A unit of `Sniff/Proc` (a `ProcXxx.pas` with its `.dfm` frame) becomes `crates/xedit-assets/src/sniff/proc_xxx.rs`. The framework is `sniff/processor.rs` (`SniffProcessor.pas`) and `sniff/main_form.rs` (the automation mode of `frmMain.pas`); `proc_update_bounds.rs` is the smallest processor, `proc_universal_tweaker.rs`, `proc_universal_fixer.rs` and `proc_check_for_errors.rs` are the big ones to copy from.

1. **Read the `.pas` and the `.dfm`.** The `.dfm` gives the defaults of the controls: `Checked = True` of a check box or radio button (absent is false), `Text = '...'` of an edit, `ItemIndex`, `Items.Strings` and `Lines.Strings` (a memo's text is its lines joined with CRLF, no break after the last), `Tag` of radio buttons. A control that a constructor or `OnShow` fills (a combo box's items, a list view of block types) is filled the same way in `on_show`.
2. **The struct.** `base: ProcBase` (`ProcBase::new(title, games, extensions)`, then `no_output = true` for a report), one field per control the processor reads (named after the control: `chkSkipRoot` is `skip_root_checked`), and one per `f...` field that `OnStart` sets. `new()` sets the `.dfm` defaults.
3. **`on_show`** reads each control from the storage with the control's default, in the order of `OnShow`: `storage.get_bool("bName", default)`, `get_integer`, `get_string`. A memo goes through `string_to_text` and `string_list_lines`, a `CommaText` through `comma_text` (not strict: spaces split), a `DelimitedText` with `StrictDelimiter` through `delimited_text`. `sniff.list` records these reads to list the settings, so read every setting in `on_show`, never in `on_start`.
4. **`on_start`** copies the controls to the run fields and raises upstream's exceptions as `DfError::new(message)` with the exact message (the run stops with it). A processor that sets `fNoOutput` there sets `self.base.no_output`. A setting that changes a process-wide global (`dfFloatDecimalDigits`, `wbRotationEuler`) saves it in `on_show` and restores it in `on_hide`.
5. **`process_file(&self, file, ctx)`** returns the new bytes, or an empty `Vec` for an unchanged file. `file.get_data()` reads the input, `file.file_name` is the path (assign it to rename the output), `file.in_archive()` is `Assigned(aFile.FileEntry)`. `fManager.AddMessage(s)` and `AddMessages(Log)` are `ctx.add_message(...)` and `ctx.add_messages(log)`; a list that a processor fills under a lock across files and writes in `OnStop` (the fixer's log file) is `ctx.proc_log`, read back in `on_stop` (which writes nothing in `ctx.dry_run`). Processors run on several threads, so `process_file` takes `&self` and keeps no state; the manager commits each file's messages and output in file order.
6. **The NIF API.** `TwbNifFile` is `NifFile` (`nif.tree`, `nif.root`; `nif.tree.nif.options` for `nif.Options`, `tree.nif.nif_version` for `NifVersion`); a method of `TwbNifFile` or `TwbNifBlock` is a free function of `data_format_nif` that takes the tree (`BlocksByType` is `blocks_by_type(tree, type, inherited)`, `block.PropertyByType(t)` is `block_property_by_type(tree, block, t, false)`: mind the default of `aInherited`, which differs between methods); a `TdfElement` method is a `Tree` method (`Elements[p]` is `tree.elements(el, p)?`, an `Option`; `EditValues[p]` is `edit_values`, `NativeValues[p]` is `native_values`, a `Variant`; `el[i]` is `tree.item(el, i)`, `Count` is `count`, `Delete(i)` is `tree.delete(el, i)`, `nif.Delete(i)` is `tree.delete(nif.root, i)`, `Name` and `Path` are `tree.name` and `tree.path`). `X.Elements['Y'].LinksTo` with a missing `Y` reads through nil upstream: write `tree.elements(x, "Y")?.ok_or_else(access_violation)?`, and the harness takes two access violations as the same error. `RootNode` of a mesh without blocks is an access violation too (`root_nodes(tree)?.first()` with `access_violation`). A string read through `EditValues` of a missing element into a variable that holds a value keeps the value upstream (`edit_values_assigned`).
7. **Delphi numbers.** `Single` variables and expressions are worked out in double precision and rounded when stored (Win64 `{$EXCESSPRECISION ON}`): compute in `f64` and cast to `f32` at each assignment to a single variable or parameter. An inline variable initialised from a `Single` (`var dm := fDepthMult;`) is a `Double`: it takes the type of the expression, which excess precision makes a double (`ProcInertiaUpdate`: rounding `dm` to a single moved the penetration depth of Oblivion meshes by an ulp). Variant arithmetic (`NativeValues[a] * NativeValues[b]`) is in double. `SameValue` of doubles is `same_value` (resolution 1E-12, not `xedit_core::delphi::same_value`), of singles `same_value_single`; `Round` is half to even, and of NaN or beyond `Int64` the integer indefinite (-2^63) where the floating point exceptions are masked; `ArcCos`, `ArcSin`, `ArcTan`, `ArcTan2`, `Sin`, `Cos` and `RoundTo` are the RTL's own, in `nif_math`. The machine code of `Sniff.exe` settles a doubt: its JCL debug data names every routine (a parser of that data and a disassembler on Python's `pefile` and `capstone` found `System.Math.ArcTan2` at 0x4717F0 and the `SameValue` overloads).
8. **Delphi strings and lists.** `SameText` is ASCII case-insensitive (`same_text`); `AnsiSameText`, `TStringList.IndexOf` (unless `CaseSensitive`) and `TStringList.Sort` compare with the user's locale (`xedit_io::encoding::ansi_compare_text`), and a sorted list's `IndexOf` finds the first of equal names. `ContainsText` is `contains_text`, `StringReplace` with `rfIgnoreCase` is `proc_universal_tweaker::replace_text`, `TPerlRegEx` is `perl_regex::PerlRegEx` (case-insensitive, `ReplaceAll` with PCRE's replacement syntax). `Format('%s', ...)` is `format!`; `IntToStr` of a variant rounds it.
9. **Register it**: `pub mod proc_xxx;` in `sniff/mod.rs`, and `ported!(group, title, proc_xxx::ProcXxx)` in place of its `pending!` line in `sniff/procs.rs` (in the order of the main form). The title must equal the unit's `fTitle` (a test checks it).
10. **Check it with the oracle.** Add one `Case` per setting path to `CASES` in `crates/xtask/src/parity/sniff.rs` (the defaults, then the settings that take other branches; `{log}` is a log file path, `{source}` a source folder of the files with the priorities of their controlled blocks changed). Build the harness in release (`cargo build --release -p xtask`) and run `target/release/xtask parity sniff --case <name> --sample 40` while porting (the first 40 files of every archive of the operation's games, unpacked to a folder), then without `--sample` for the gate. A difference names the file: run both sides on it alone (`-P:<file> -threads:1`) and diff their JSON (`Convert to and from JSON` with `sDigits=16`) and their bytes (`cmp -l`) to find the element. Sniff's threads share state: a file with an access violation is run again alone before it counts.
11. **Record it**: the unit in `upstream-map.toml` (`ported`, `rust` the module), the frame's events in `coverage/ledger.toml` (`covered` by `sniff.run` when they change what is processed, `presentation` with a note otherwise), the result in the phase's Status in `docs/PLAN.md`, and an `UPSTREAM-QUIRK:` comment for every upstream bug kept.
